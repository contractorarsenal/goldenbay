# Project photography

Drop approved client project photos here using descriptive, lowercase, hyphenated names, e.g.

    kitchen-remodel-willow-glen-01.jpg
    adu-detached-backyard-san-jose-01.jpg
    addition-second-story-front-01.jpg

Reference them by filename in `<ProjectImage file="kitchen-remodel-willow-glen-01.jpg" ... />` or in `src/data/projects.ts`.
Provide originals at >= 2400px on the long edge (JPEG/PNG/HEIC converted to JPEG). The build generates AVIF + WebP at 480-2200px.
Never place stock or generated images here. See docs/HOMEPAGE-PHASE-1.md for the shot list and aspect ratios.
